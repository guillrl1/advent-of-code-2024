# Advent of Code 2024

Soluciones de los cinco primeros días del [Advent of Code 2024](https://adventofcode.com/2024), en C++ y Python.

Las entradas de cada puzzle no se incluyen, porque Advent of Code pide no compartirlas.

| Carpeta | Lenguajes |
|---|---|
| `Dia1` | C++ |
| `Dia2` | C++ y Python |
| `Dia3` | Python |
| `Dia4` | Python |
| `Dia5` | Python |
